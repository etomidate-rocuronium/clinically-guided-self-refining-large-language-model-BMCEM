# Clinically-guided-self-refining-large-language-model-BMCEM
Github repository containing environment.yml and code implemented for the manuscript entitled "Clinically-guided self-refining large language model for automated diagnostic confirmation of suspected acute stroke in the emergency department: a retrospective development and internal validation study" submitted to BMC emergency medicine. Per sanitation protocol, directories and huggingface tokens have been replaced with place holders. You may opt to run scripts either using torchrun at the terminal or using CPU (for instance, I trained and evaluated BioClinical BERT on the CPU). Environmental variables may need to be exported, such as HF_token.
